Add someone to the team

This is the step that actually matters: add them as a GitHub collaborator so they get real access. On GitHub: your repo → Settings → Collaborators and teams → Add people → enter their GitHub username → choose Write (editor/uploader) or Admin (administrator). They'll get an invite email; once accepted, they show up above. Then have them log into this admin panel and add their own personal access token in Settings (⚙) — their token only works if GitHub has actually granted them access, so permissions are enforced for real.
